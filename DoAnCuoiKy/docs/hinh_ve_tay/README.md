# Sơ đồ (vẽ bằng công cụ vẽ sơ đồ)
Mỗi người tự vẽ sơ đồ phần mình phụ trách bằng **draw.io** (https://app.diagrams.net) hoặc ứng dụng vẽ sơ đồ khác, xuất PNG/JPG, đặt tên `<ten>_<noi-dung>.png`. Nên lưu kèm file gốc `.drawio` để sửa sau.
- danh_so_do_tong_the – toàn bộ hệ thống 2 nhánh (phân loại, phân cụm) và web demo
- loc_so_do_tien_xu_ly – từ tiêu đề thô đến vector đặc trưng
- nhan_so_do_xgboost – quy trình SVD → XGBoost, boosting vs bagging
- thinh_so_do_phan_cum – quy trình phân cụm và các thuật toán so sánh
Trong báo cáo chú thích "Hình X.Y – <nội dung> (sơ đồ tự vẽ – <tên người vẽ>)".
