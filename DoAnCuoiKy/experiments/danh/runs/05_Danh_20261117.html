05 – SVM tuyến tính: ablation đặc trưng, tinh chỉnh C, kiểm chứng Group split

Người thực hiện: danh (Huỳnh Quốc Danh)
Mục tiêu: Trả lời RQ1 (đặc trưng nào giúp) và chọn mô hình cuối cùng cho hệ thống.

Quy tắc: chạy TỪNG ô một, đổi tham số rồi chạy lại; mỗi ngày làm xong thì git add + git commit -m "<mô tả đúng việc đã làm>" + git push. Cuối buổi xuất HTML: python ../scripts/export_notebook_html.py <notebook> danh.

Các bước:

  1. Ablation: word → char → hybrid → full (cùng C).
  2. Thử char_ngram (2,4), (3,5), (3,6).
  3. Quét C ∈ {0.03, 0.1, 0.3, 1, 3} có CV.
  4. class_weight='balanced' có giúp 3 lớp tủ lạnh/tủ đông?
  5. Chạy lại cấu hình tốt nhất với split='group'.
  6. GridSearchCV nhỏ (tùy chọn) và kết luận mô hình chọn.

7. Mô hình chọn và lý do

  • Đặc trưng: Hybrid TF-IDF = word n-gram (1,2) + char_wb n-gram (2,4), sublinear_tf, min_df=2. Vì: thêm n-gram ký tự tăng Macro-F1 từ 0.9679 lên 0.9924 (+2,45 điểm; danh_20261113_164215 → _164224), do ~1/5 tiêu đề chỉ có hãng + mã model hoặc tiếng Đức mất dấu, word n-gram không đọc được còn char n-gram nắm được tiền tố mã model. Phạm vi (2,4) tốt hơn (3,5) thật sự trên 5-fold CV: 0.99066 ± 0.00095 so với 0.98890 ± 0.00080, chênh 0.0018 > std (_170717, _170850); (3,6) kém hơn (0.9910), (2,5) ngang nhưng chậm hơn. Không dùng thêm đặc trưng hình thái + merchant vì không cải thiện (full 0.9920 ≤ hybrid 0.9924).
  • Mô hình: LinearSVC (SVM tuyến tính). Vì: tốt nhất trong các mô hình đã thử (NB 0.9663, Logistic 0.9656, Decision Tree 0.9408, XGBoost 0.9771, Random Forest 0.9733 – theo nhật ký nhóm và giữa kỳ), phù hợp dữ liệu văn bản thưa nhiều chiều, huấn luyện chỉ vài giây. class_weight='balanced' không giúp (0.9914 < 0.9920; _164414) nên giữ mặc định.
  • Tham số: Kiểm chứng trên sản phẩm mới (Group split theo Cluster ID): Macro-F1 0.9875 (danh_20261113_231233), giảm 0.54 điểm so với chia ngẫu nhiên – mô hình vẫn tổng quát tốt.

import os, joblib
from sklearn.metrics import ConfusionMatrixDisplay
from sklearn.model_selection import train_test_split

# Huấn luyện lại mô hình cuối và ghi nhật ký
res, pipe = run(member='danh', model='svc', features='hybrid', params={'C': 3.0},
                char_ngram=(2, 4), exp_name='final_model', show_report=False)

# Chia lại đúng như lúc huấn luyện (random_state=42) để lấy tập Test
df = load_data(); df['clean'] = df.title.map(clean_title)
X, y = df[['clean', 'merchant_id']], df.category_label.values
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.2, stratify=y, random_state=42)
pred = pipe.predict(Xte)

# Ma trận nhầm lẫn, lưu kèm nguồn gốc hình
fig, ax = plt.subplots(figsize=(9, 8))
ConfusionMatrixDisplay.from_predictions(yte, pred, ax=ax, xticks_rotation=45, colorbar=False)
ax.set_title('Confusion matrix – mô hình cuối (hybrid char 2-4, LinearSVC C=3)')
save_fig(fig, 'danh_cm_mo_hinh_cuoi', notebook='05_Danh_SVM_DacTrung.ipynb', member='danh',
         cell='Mục 8', y_nghia='(tự viết)')

# Lưu mô hình cuối
os.makedirs('../models', exist_ok=True)
joblib.dump(pipe, '../models/final_svc_hybrid24_C3.joblib', compress=3)

# Danh sách mẫu bị đoán sai
err = df.loc[Xte.index].assign(pred=pred)
err = err[err.category_label != err.pred]
err[['product_id', 'title', 'merchant_id', 'category_label', 'pred']].to_csv(
    '../experiments/danh/loi_mo_hinh_cuoi.csv', index=False, encoding='utf-8-sig')
print('Số mẫu sai:', len(err))
err.groupby(['category_label', 'pred']).size().sort_values(ascending=False).head(10)

Ba ngành này có chung hãng (Liebherr, Bosch, Gorenje, Hotpoint, Smeg...) và mã model gần giống nhau, nên khi tiêu đề không có từ "fridge"/"freezer" thì mô hình chỉ còn dựa vào hãng và tiền tố mã model.

Kết luận:

  • Hơn một nửa lỗi đến từ tiêu đề chỉ có hãng + mã model. Với những mẫu này, ngay cả người đọc cũng không đoán được ngành nếu không tra mã, nên đây gần như là giới hạn của dữ liệu chỉ có tiêu đề.

  • Hướng cải thiện có thể làm: (1) chuẩn hóa các từ tiếng Đức/Pháp bị mất dấu (k hlschrank → fridge, gefrier → freezer, frig rateur → fridge) trước khi tạo TF-IDF; (2) bổ sung đặc trưng dung tích (307l, 122l 62l): tiêu đề có hai mức dung tích thường là tủ lạnh kết hợp ngăn đông; (3) không cố sửa phần nhãn sai vì đó là nhiễu của dữ liệu gốc.

import time
from sklearn.model_selection import train_test_split
from sklearn.pipeline import Pipeline
from sklearn.svm import LinearSVC
from sklearn.metrics import f1_score
from run_experiment import build_features

df = load_data(); df['clean'] = df.title.map(clean_title)
X, y = df[['clean', 'merchant_id']], df.category_label.values
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.2, stratify=y, random_state=42)

kq = []
for ti_le in [0.05, 0.1, 0.25, 0.5, 0.75, 1.0]:
    # Lấy ti_le phần của tập Train (giữ tỉ lệ các ngành); tập Test giữ nguyên 7.063 mẫu
    if ti_le < 1:
        Xs, _, ys, _ = train_test_split(Xtr, ytr, train_size=ti_le, stratify=ytr, random_state=42)
    else:
        Xs, ys = Xtr, ytr
    pipe = Pipeline([('feat', build_features('hybrid', char_ngram=(2, 4))), ('clf', LinearSVC(C=3.0))])
    t = time.time(); pipe.fit(Xs, ys); tg = time.time() - t
    f1 = f1_score(yte, pipe.predict(Xte), average='macro')
    dong = dict(ti_le=ti_le, n_train=len(ys), test_f1_macro=f1, train_time_s=tg)
    log_generic('danh', 'learning_curve', dong)
    kq.append(dong)
